# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`。

## 进洞许可与出洞释放闭环

「进洞调度」页签覆盖班组进洞的完整闭环，规则、存储、展示三层分离：

- `lib/permit-rules.js`：纯许可规则（不接触文件与 HTTP）
  - 同一洞穴同一分区同一时段只允许一组进洞，时间窗重叠即拒
  - 路线含「暂停开放」样点、领队未完成当日巡测登记、字段缺失，一律拒绝且不落库（不留半张许可）
  - 同班组/分区/进洞时间/名单的重复或并发申请沿用首次许可（进程内写锁 + 幂等键）
  - 延长预计出洞时间分「申请 → 重确认」两步，确认时重新校验整段时段冲突
  - 出洞核对全员、实际路线与异常装备：缺员或装备异常只生成「搜索待办」，许可转「待搜索」，额度不释放；待办全部处理后才可释放
  - 逾期许可在看板快照中自动置顶
- `lib/store.js`：`db.json` 读写与写锁，`permits`/`todos` 只能通过领域动作变更
- `server.js`：HTTP 装配；看板走 `GET /api/board/permits`，派生状态每次现算
- `public/permit-board.js`：调度页展示（分区占用、申请、出洞核对、延长、搜索待办、履历），刷新后全部由服务端记录重建
