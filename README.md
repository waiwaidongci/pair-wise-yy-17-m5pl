# 钟乳石洞穴微环境巡测

## 启动

```bash
npm install
npm start
```

默认地址：http://localhost:3912

数据保存在`data/db.json`，后续可以继续增量迭代。

## 进洞许可闭环（补班组）

三层分离：

- 规则层 `permit-rules.js`：纯函数，无 IO。负责进洞校验、时段冲突、延期重确认、出洞核对、逾期巡检。
- 存储层 `server.js`：`permits` / `todos` 只能通过 `/api/permit/*` 专用接口写入，写操作串行锁防并发；拒绝申请时不落任何记录。
- 展示层 `project.config.js` + `public/`：视图字段、状态色调在配置中描述，页面只渲染与调接口。

规则要点：

- 同一分区同一时段只许一组进洞（时间区间重叠即冲突）；同班组重复或并发申请沿用首次许可。
- 路线含「暂停开放」样点，或领队无当日巡测登记 → 整单拒绝，不留半张许可。
- 出洞核对全员名单、实际路线、异常装备；缺员或装备异常只生成 `todos` 搜索待办，许可继续占用额度。
- 延长预计出洞时间先进入「待确认延期」，须重确认；超过预计出洞时间自动转「逾期」并在履历留痕、列表置顶。
- 状态：已许可 → 进洞中 →（待确认延期 / 逾期）→ 已出洞。刷新页面后占用、待办与履历均来自同一存储，保持一致。
